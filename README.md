# Machine Learning the Physical World 🔬🤖

**Companion notebooks for DevFest Chennai 2026**

How can AI help us understand the physical world? Explore two scientific applications through interactive Python notebooks, from learning the laws of cooling to discovering materials from computational data.

No local installation required. Everything runs in **Google Colab**.

## 🚀 Get started

Choose a notebook and run it in your browser.

### 1. ☕ Physics-Informed Neural Networks: Cooling Coffee

**Can a neural network learn the physics of a cooling cup of coffee?**

Explore a physics-informed neural network (PINN) that combines data with the differential equation governing Newton's law of cooling. See how physical laws can guide learning, rather than relying on data alone.

[**Open the coffee-cooling notebook in Google Colab →**](https://github.com/aghosh92/DevFest_Chennai_2026/blob/main/Notebooks/Notebook_I_PINN_coffee.ipynb)

*What you'll explore*
- Newton's law of cooling and its differential equation
- How neural networks represent physical behavior
- How physics-based constraints enter the learning process

### 2. 🧪 AI for Materials Discovery: Materials Project

**How can we use computational materials data to find promising materials?**

Explore materials data from the [Materials Project](https://materialsproject.org/) and see how computational databases can support materials discovery. Investigate material properties and learn how data-driven approaches can help narrow the search for useful materials.

[**Open the Materials Project notebook in Google Colab →**](https://github.com/aghosh92/DevFest_Chennai_2026/blob/main/Notebooks/Notebook_II_Mat_Proj.ipynb)

*What you'll explore*
- Accessing and exploring materials data
- Filtering materials using scientifically meaningful properties
- Connecting data-driven workflows to real scientific questions

## 🛠️ What you need

- A Google account to use Google Colab
- A web browser
- Curiosity about AI, coding, and the physical world

You do not need to install Python or configure a local development environment.

## 💡 How to use the notebooks

1. Open a notebook using its Google Colab link.
2. Sign in to your Google account if prompted.
3. Select **Runtime → Run all**, or execute the cells one at a time.
4. Read the explanations, inspect the outputs, and experiment with the code.

Some cells may require an internet connection or an API key. Follow the instructions inside the relevant notebook if prompted.

## 🌍 The bigger picture

Scientific AI is about more than predicting an answer. It can help us connect data to physical laws, explore large spaces of candidate materials, and develop a deeper understanding of how the world works.

These notebooks offer two entry points into that journey.
